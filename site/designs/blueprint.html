RiskMandate

The insurability layer for agentic AI
Originriskmandate.ai
Sheet checked2026-11-20

Specification

RiskMandate writes an Agent Behaviour Policy for each AI agent you run: everything it can actually reach, what you authorised it to do, the gap between the two, and what really stands in the way.

The product is the Agent Behaviour Policy, or ABP: a written record, for one agent in one deployment, of what the agent can do, what it was authorised to do, the gap between them, and the barrier on each.2

The ABP "describes and it does not judge, so it carries no score." It is read-only and never sits in the agent's request path; enforcement, when wanted, runs on the customer's side.2 3

Its stated direction is insurability: from a behaviour policy, to a Licence to Operate, to an agent that can be insured. The company says plainly that the later steps are templates and designs, and "No insurer has agreed to anything on this page."4

It sits beside security vendors rather than against them: "We don't detect. We don't remediate. We make the business own the risk."5

Stated purpose: “RiskMandate creates and sells Agent Behaviour Policies: for one agent in one deployment, what it can actually reach, what you authorised it to do, and the gap nobody has looked at.” (RiskMandate's own one-line description)1

Intended users

User 1Anyone who runs AI agents, from one agent to hundreds.10
User 2People who gave an assistant access to a repository, a mailbox or a cloud account.6
User 3Investors with a portfolio, and companies that will be diligenced.6
User 4Underwriters, risk committees and boards, the audiences the brand is meant to speak to.1

Process

  1. The mandateWhat you authorised the agent to do, drawn out of you.2
  2. The grantWhat the agent can actually reach, measured from the deployment.2
  3. The deltaThe difference between the two, derived and never edited.2
  4. The barrierWhat stands in the way, per capability: none, an expectation, a setting or a boundary. Only a boundary counts as a control.2

Components

Agent Behaviour PolicyThe record for one agent in one deployment: reach, mandate, gap and barrier.2 8
ABP library16 template policies published free, for tools such as Claude Code, GitHub Actions and the Microsoft 365 connector.11
SHarnessAn open-source secure harness, Apache-2.0, that turns a policy into one the Linux kernel holds. The site says it is partly running.9
Licence to OperateA template in every published vault; not yet issued.12
Insurability IndexA 0 to 100 score across five dimensions; a design, not yet a product.4
Customers site"Put a behaviour policy on your agent, in five minutes", with six examples for Claude or ChatGPT.13
